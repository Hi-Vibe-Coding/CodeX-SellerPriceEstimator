常规公式：单品售价 = 采购成本 + 国内物流 + 国际物流(含货代) + 平台抽佣 + 获客成本 + 退货预留 + 单品售价×利润百分比
填入值后：单品售价 = 115 + 6 + 67 + 单品售价×0.05 + 0 + 10 + 单品售价×15
合并固定成本：单品售价 = 198 + 单品售价×0.05 + 单品售价×15
移项求解：单品售价 × (1 − 0.05 − 15) = 198
计算分母：单品售价 = 198 ÷ 0.8
最终结果：单品售价 = 247.5元 = 36.9美元（利润百分比 15%）
